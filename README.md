## Additional Info

This is a Next.js app created using below command -

```bash
npx create-next-app@latest
```
The above command, will ask for app name, language used.. I have selected options based on my requirements


Run the application locally -

Firstly, navigate to project directory and install the dependencies :

```bash
npm install
```

Check for below dependencies -

```bash
npm -v
```

My version is 10.8.3

```bash
node -v
```

My version is v22.9.0

```bash
next -v
```

My version is Next.js v14.2.15

After ensuring the dependencies are in place, run the development server :

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
